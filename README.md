# -Cafe-Billing-Customer-Analytics-System-Advanced-Excel
Developed a complete café business model using Advanced Microsoft Excel and VBA, combining secure login authentication, automated billing, and an interactive dashboard to analyze customer behavior and sales performance.
	Key Responsibilities & Features:
•	Designed and implemented a VBA-based login system to control user access and secure the application.
•	Created a front-end billing entry system using Excel macros, advanced formulas, and form controls for efficient customer order processing.
•	Automated bill generation, including item-wise pricing, GST calculation, and total amount computation.
•	Developed a customer and sales analytics dashboard to monitor key performance indicators (KPIs).
•	Analyzed item-wise sales, day-wise revenue, seasonal demand, table-wise sales, and customer visit timing (morning/afternoon/evening).
•	Used interactive filters and slicers to enable dynamic data exploration and quick business insights.
•	Implemented Pivot Tables and Pivot Charts (bar, column, pie, and area charts) for clear data visualization.
•	Structured backend data storage to support accurate reporting and historical analysis.
•	Tools & Technologies: Advanced Excel, VBA (Macros), Excel Formulas, Pivot Tables, Pivot Charts, Dashboards, Data Analysis
